# Support for CC2UMAConverter

Need help with CC2UMAConverter? Here are the best ways to get support:

## 1. Check the README

The [README.md](readme.md) contains comprehensive instructions on installation, usage, and known limitations for both the Character Creator 4 and Daz3D pipelines.

## 2. GitHub Issues

If you've encountered a bug, have a feature request, or need help with a specific problem that isn't covered in the documentation, please [open an issue](https://github.com/valentinwinkelmann/CC2UMAConverter/issues).

When opening an issue:
* Use the provided **Bug Report** template if something is broken.
* Use the **Feature Request** template if you have an idea for improvement.
* Provide as much detail as possible (Blender version, Unity version, screenshots, error logs).

## 3. General Questions

For questions not suitable for an issue (e.g., general workflow advice), feel free to open a discussion or ask in the relevant community spaces if available.

Please be patient when waiting for a response, as this project is maintained in free time.
